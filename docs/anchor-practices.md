**Дата:** 2026-06-14
**Автор:** CPO
**Для:** CTO (детерминированная доставка якорей, тот же транзит-движок, что tideline T-2) + Head of Design (Anchor card F10) + контент-QA
**База:** дизайн-стратегия v2 (F10 Anchor, F5 compose) · нарративный путь (биты B10–B12) · контент-пак v1 (Hunger-оси) · концепт Inner Tide
**Что это:** контент и логика «одного маленького якоря в день» — что делать в окно высокой воды. **0 токенов** (детерминированно).

> **Гардрейлы.** Якорь = «оседлать волну», встретить тягу и дать **настоящую нужду напрямую** — НЕ правила еды, НЕ ограничение, НЕ результат. Никаких health-claims (вес/диета/калории/порции/«ешь медленнее, чтобы…»). Еда упоминается только как «ближайший берег» / «не из кухни». Практики — mindfulness/journaling-стиль (для App Review: общее благополучие, не медицина). Тон Весты: тепло, без давления.

## 1. Принцип якоря (почему так)
Тяга тянется не к еде, а к **нужде** (P-1, ось Hunger): забота / простор / порядок / новизна… Якорь даёт эту нужду **напрямую**, поэтому еда перестаёт быть единственным берегом. Это и есть «ride, don't fight»: не бороться с приливом, а встретить его и дать телу то, что оно на самом деле просит. Каждый прожитый якорь добавляет слой к твоей линии (F5 compose) — видимый прогресс без счётчиков.

**Связь с P-1:** якорь выбирается по `moon_sign → hunger_key`. Сигнатура объясняет «за чем тянет», якорь — «вот как это дать». Один смысловой стержень через весь продукт.

## 2. Логика high-tide окна (детерминированно, 0 токенов)

| Шаг | Правило |
|---|---|
| Базовое окно | = натальный `timing_band` (early/midday/evening/late); solar → «across the day», дефолт midday или выбор юзера |
| Модуляция амплитуды | по `moon_phase` (full → выше, new → ниже) и в день `moon_conjunct_natal` — пик сильнее |
| Сдвиг пика | транзитная Луна по знаку/дому слегка смещает время пика в пределах окна |
| Доставка якоря | push (F8) за **30–60 мин до пика** окна; якорь живёт на Today (F10) весь день |
| Solar/без времени | окно «по дню»; якорь всплывает в дефолт-слот (midday) или в выбранное юзером время |

Тот же транзит-движок, что рисует tideline (T-2) — отдельных вычислений не нужно: окно = точка high-water на сегодняшней линии.

## 3. Библиотека якорей (12 Hunger × 3) + Universal

Формат: `title` · `action` (5–10 мин, что сделать + что заметить). Все — дать нужду напрямую, не про еду.

### Aries — *release, move it out*
| title | action |
|---|---|
| Move the water | Перед окном — 5 мин движения: стряхни тело / быстрый шаг / один трек танца. Заметь, куда уходит заряд. |
| One hard exhale | Встань, 10 медленных сильных выдохов — дай заряду выйти из тела. |
| Name the heat | Скажи вслух, что на самом деле хочешь сделать/сказать. Тяга — это энергия, ищущая дверь. |

### Taurus — *something solid and calm*
| title | action |
|---|---|
| Find solid ground | Стопы плашмя, ладони на что-то твёрдое (стол, стена), 2 мин. Пусть устойчивость придёт извне, не из кухни. |
| Comfort that isn't food | Тёплый плед, мягкая текстура, знакомый предмет — дай телу комфорт напрямую. |
| Slow one thing | Медленно сделай тёплый напиток, почувствуй тепло. Спокойный ритуал, чтобы прилив осел. |

### Gemini — *a change of channel*
| title | action |
|---|---|
| Switch the channel | 5 мин другого входа: трек, страница, выйди наружу. Дай уму новизну, к которой он тянется. |
| Write the buzz | 3 мин вылей мысли на бумагу — плоскому дню вернётся движение. |
| One curious thing | Найди/заметь одну новую вещь рядом. Новизна без кухни. |

### Cancer — *care*
| title | action |
|---|---|
| Care that isn't food | Завернись в плед, согрей ладони о кружку, напиши тёплому человеку — дай себе заботу, к которой тянет. |
| Hand on heart | 2 мин: ладонь на грудь, медленный вдох. Побудь себе мягкой матерью прямо сейчас. |
| Tend one small thing | Полей растение, поправь один угол — направь заботу вовне. |

### Leo — *warmth, to feel seen*
| title | action |
|---|---|
| Be seen, gently | Напиши кому-то, поделись одной вещью из дня. Тяга хочет тепла — дай ей человека. |
| Warm light | 3 мин в тёплом свете / на солнце. Впусти тепло без кухни. |
| One thing you're proud of | Назови вслух или запиши. Дай себе быть увиденной собой. |

### Virgo — *a sense that things are handled*
| title | action |
|---|---|
| Handle one thing | 5 мин: разбери одну поверхность или пункт списка. Спокойствие, к которому тянет, — из порядка, не из еды. |
| Brain-dump the list | 3 мин выпиши все открытые петли — дай уму их отложить. |
| One tidy ritual | Медленно выровняй своё пространство. Порядок успокаивает прилив. |

### Libra — *ease and a softer room*
| title | action |
|---|---|
| Smooth one edge | Реши или отложи одно напряжение (сообщение, мелкое решение). Тяга хочет лёгкости. |
| Make the room soft | Подправь свет, музыку, зажги свечу — создай гармонию вокруг. |
| Reach out warmly | Тёплое сообщение кому-то — верни баланс через связь. |

### Scorpio — *something that meets you fully*
| title | action |
|---|---|
| Name what's underneath | 3 мин запиши настоящее чувство, без фильтра. Глубину надо встретить, не закопать. |
| One intense, clean thing | Холодная вода на ладони, сильная музыка, глубокий вдох — встреть интенсивность напрямую. |
| Private 5 minutes | Закрытая дверь, только ты и чувство. Глубина уважена. |

### Sagittarius — *room to breathe*
| title | action |
|---|---|
| Open a window of space | Выйди, посмотри вдаль, 5 мин. Тяга хочет простора — дай ей горизонт. |
| Plan one escape | Запиши одну вещь, которую ждёшь впереди. Стены раздвигаются. |
| Move toward open | Короткая прогулка в новое место. Простор без кухни. |

### Capricorn — *a moment where everything's handled*
| title | action |
|---|---|
| Set one thing down | Назови одну задачу, которую сегодня отпустишь. Нагрузка ослабнет без еды. |
| One handled corner | Доведи одну мелочь до конца. Чувство «всё под контролем» в миниатюре. |
| Permission to stop | Напиши: «на сейчас этого достаточно». Контроль через выбор отдохнуть. |

### Aquarius — *room to step back*
| title | action |
|---|---|
| Step back | 5 мин одна, без входящего шума. Та дистанция, к которой тянет. |
| Wide view | Опиши ситуацию сверху, как наблюдатель. Отстранение без кухни. |
| One thing your way | Сделай что-то мелкое нестандартно — верни себе пространство. |

### Pisces — *a gentler edge*
| title | action |
|---|---|
| Soften the edges | Тёплая вода на ладони, тихая музыка, приглушённый свет — дай мягкость напрямую. |
| Let it be vague | 5 мин без цели — помечтай, порисуй, поплыви. Края размываются по-доброму. |
| Comfort the feeling | Ладонь на грудь, доброе слово себе. Утешь без еды. |

### Universal — *tide basics* (для любого, для ротации/разнообразия)
| title | action |
|---|---|
| Meet the wave | Когда тяга приходит — пауза 60 сек, просто почувствуй, как она поднимается и проходит гребень, как волна. Действовать не обязательно. |
| Name the tide | Назови, к чему на самом деле тянешься сейчас (отдых, забота, простор…). Называние смягчает тягу. |
| One kind sip / breath | Стакан воды или 5 медленных вдохов, медленно. Маленькая доброта в высокой воде. |
| Ride, don't fight | Позволь тяге быть, не оценивая её. Заметь — она проходит, как любой прилив. |

## 4. Шаблоны копи (голос Весты, EN)

**Morning surface (push F8, за 30–60 мин до пика):**
> *“Near {window} the pull tends to rise. Here's one small way to ride it: {anchor_title} — {anchor_action_short}.”*

**Anchor card (Today, F10):** `{anchor_title}` + `{anchor_action}` + тихая строка *“No fixing. Just ride this one.”*

**Done line (рандом из набора, чтобы не повторялось):**
- *“That's one wave, ridden. Your line just gained a layer.”*
- *“You met the water instead of fighting it. That's the whole practice.”*
- *“One more layer in your rhythm. The tide remembers.”*

**Skip (без наказания, F11):** *“The tide doesn't keep score. It'll come again — I'll be here.”*

**Evening check (B11, ощущения не числа):** *“How did the tide feel today?”* → Settled / Mixed / Hard
- Settled → *“Good. You rode it.”*
- Mixed → *“Some waves are like that. You still showed up.”*
- Hard → *“Hard tides pass. You met it — that's enough for today.”*

## 5. Селект и ротация (детерминированно)

| Правило | Значение |
|---|---|
| Пул юзера | 3 якоря его `hunger_key` + 4 universal = **7 уникальных** → покрывают 7-дневный триал без повтора |
| Порядок триала | день 0–2: чередуем sign-specific ↔ universal (начинаем с sign-specific «Care that isn't food»-типа — сильнее узнавание) |
| Daily после триала | продолжаем ротацию пула; повтор не раньше чем через 7 дней |
| Compose (F5) | каждый `done` → +1 слой к линии; пропуск → разрыв, заполняется на возврате |
| v2-хук (позже) | вес выбора по теме сегодняшнего транзита (напр. в день high-care — приоритет care-якоря). Не нужно для Phase 1 |

## 6. Контракт переменных (вход → выход) для CTO

**Вход:**
```
moon_sign        → hunger_key (Aries…Pisces)
timing_band      → window_phrase (mornings/midday/evenings/after dark/across the day)
transit          : { moon_phase, peak_time, conjunct_natal_day }
history          : [delivered_anchor_ids]   // для анти-повтора
user_pref        : optional manual window (для solar/выбора)
```
**Выход на день:**
```
high_tide_window : { start, peak, end }      // из tideline-движка (T-2)
anchor           : { id, title, action, action_short }
push_copy        : morning surface (§4) с подставленными {window}/{anchor}
done_copy        : random из набора (§4)
```

## 7. Покрытие, зависимости, QA
- **Объём v1:** 12×3 + 4 universal = **40 якорей**; 3 done-варианта; evening-набор. Полностью детерминированно, 0 LLM.
- **Зависимость:** P-2 использует тот же транзит-движок, что tideline (CTO T-2) — окно = high-water точка дня. Отдельной астро-логики не требует.
- **QA:** прогон 7-дневной ротации на 3 тест-профилях (нет повторов, тон выдержан); guardrail-линт всех строк (P-4) — особое внимание: ни одна практика не про ограничение/правила еды.
- **Безопасность/App Review:** практики — общее благополучие (внимание, дыхание, journaling, забота), не медицина; опциональны; без обещаний результата.
