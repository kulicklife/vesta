## P-1 (CPO) · Приливная сигнатура из карты — **owner: CPO + контент** · Prio P0
**Что.** Определить, как из натальной карты выводится «форма прилива» (например: deep/shallow, early/late, choppy/even) и как она формулируется в reveal языком воды.
**Зачем (метрика).** Это топливо метрики №1 `recognition_yes` — точность «это про мой день» решает всю воронку.
**Критерии приёмки.**
- Заданы 3–5 осей приливной сигнатуры + правило вывода каждой из элементов карты (Луна/доминанты/аспекты), детерминированно.
- Для 10+ реальных карт сгенерированы сигнатуры; 100% проходят guardrail-линт (нет health-claims).
- Носитель-тест «узнаю себя» на 5 тест-юзерах из ЦА ≥ 4/5 «да».
- Каждая формулировка ≤ 2 предложений, тон наставницы, эзо-термин с человеческим переводом.
**Зависимости.** `analyze_chart(locale='en')` (есть).
**Артефакт.** Таблица «ось сигнатуры → правило вывода → 2–3 примера копи (EN)».

## P-2 (CPO) · High-tide-окно + Anchor-практики — **owner: CPO** · Prio P0
**Что.** Логика «когда сегодня высокая вода» (детерминированно из транзитов) и библиотека 5–10-мин практик-«якорей», по одной на день.
**Зачем (метрика).** Ядро S2/S4: `path.dayN_done`, `value_felt`, retention. Без этого Today пустой.
**Критерии приёмки.**
- Для дня определяется high-tide-окно (час/диапазон) + 1 практика; правило — без LLM-токенов.
- Банк ≥ 30 практик (14 дней триала + запас), язык ощущений/наблюдения, НЕ результата; проходят guardrail.
- Вечерний чек — шкала ощущений (Settled/Mixed/Hard), не числа.
- Практика выполнима за 5–10 мин и не требует оборудования/еды-как-цифр.
**Зависимости.** Транзит-движок (kerykeion/swisseph, есть).
**Артефакт.** Спека `tide/today` (окно+практика+evening_check) + банк практик (CSV/JSON).

## P-4 (CPO) · Контент-гайд «голос прилива» + ban-лист — **owner: CPO** · Prio P0
**Что.** Канонический voice-гайд под Inner Tide + машинный ban-лист health-claims для контент-линта.
**Зачем (метрика).** Соответствие позиционированию и App Review (health-claims = риск реджекта); защищает все UI-строки и push.
**Критерии приёмки.**
- Словарь Да/Нет (tide/pull/ebb/flow/rise/settle/your nature/today vs weight/kg/diet/calorie/BMI/doctor/willpower/lose/«result in N days»).
- 6–10 примеров «✗ не так → ✓ так (Vesta)».
- Regex ban-лист отдан CTO для CI-линта (§12.3 дев-спеки).
- Прогон всех существующих EN-строк reveal/paywall/push → 0 нарушений.
**Зависимости.** Бренд-бук, концепт Inner Tide.
**Артефакт.** `voice-guide.md` + `banlist.txt`.

## P-6 (CPO) · Метрик-план событий S0–S6 — **owner: CPO + data** · Prio P0
**Что.** Финальный event-spec воронки (имена snake_case, свойства, правила срабатывания) для инструментирования.
**Зачем (метрика).** Без 100% событий + атрибуции UA-гейт не открывается; нельзя мерить recognition_yes/trial→paid.
**Критерии приёмки.**
- Покрыты все стадии: `acquire.*`, `quiz.complete`, `chart.lit`, `recognition_yes/no`, `trial_start`, `path.dayN_done`, `value_felt`, `paywall.view`, `trial_to_paid`, `daily.opened/engaged`, `dialog.message(tokens,cost,capped)`, `tide.viewed`, `anchor.done`.
- Для каждого: триггер (точно) + обязательные свойства + идентичность (anon→user мерж через web→app handoff).
- Дедуп-правило для `*.view`.
**Зависимости.** Согласовать с CTO (T-9 аналитика).
**Артефакт.** `events.md` (таблица) — вход для CTO-инструментирования.

## T-1 (CTO) · Дизайн-токены «water at every hour» — **owner: CTO/eng** · Prio P0
**Что.** Токены в код (RN): цвет (вкл. aqua + 5 сред env), типографика (Spectral/Onest/Mono + Dynamic Type), spacing/radius/glow, motion.tide и haptic.tide неймспейсы. Семантические алиасы (`surface.bg/card`, `text.*`, `accent`) → маппинг на текущую среду.
**Зачем (метрика/риск).** Разблокирует ВСЕ экраны и фичи F1–F12; гарантирует консистентность и a11y; без токенов экраны расходятся.
**Критерии приёмки.**
- `tokens.ts` + `type.ts` + `motion.ts` собраны; 5 сред (dawn/day/dusk/night + parchment) с проверенным контрастом AA (текст ≥4.5:1) в каждой.
- Шрифты подключены (expo-font), Dynamic Type до AX2 не ломает шкалу.
- Правило золота в коде: `GoldAccent`-обёртка; линт запрещает сырой `color.gold` вне неё.
- `cross-env` cross-fade реализуем из токенов; reduce-motion → мгновенная смена.
- Демо-экран с переключателем сред показывает корректный контраст и типографику.
**Зависимости.** Бренд-палитра §3.2 стратегии v2; Addendum A.0.
**Артефакт.** Токен-пакет + демо-скрин + краткий README использования алиасов.

## Порядок и зависимости
```
T-1 (токены) ───────────────┐
P-4 (voice+banlist) ─────────┤
P-1 (приливная сигнатура) ───┼──► разблокирует Lighting/Reveal (T-5) и Today (T-2)
P-2 (high-tide + anchor) ────┤
P-6 (events) ──► T-9 аналитика (параллельно)
```
**Рекомендация:** P-1, P-2, P-4, P-6 (CPO) идут параллельно с T-1 (CTO) — это «нулевая неделя». Затем стартует критпуть полиша: T-2 (tideline) + T-3 (wheel) + T-5 (Lighting) → T-4 (haptic) → T-8 (dialogue).
